# WELCOME TO ETHICAL


Ethical is a prototype for a roguelike game
Ethical was made for `terra`, a YSWS made by hack club.
Ethical, like many roguelikes, is a terminal-based game, made in C++
Current Features include: 
Movement
Map Generation (Unfinished)
Enemies (Unfinished)
UI Rendering
UI Modification/Selection

Libraries Used:
Ncurses (c variant)
cstring
cstdlib
map
vector

Class-Based, Expandable Enemies (super easy to add new enemies!)
The goal of the game will be to reach the tenth floor and defeat Countess Shel, a evil lich.
Currently, the game exists as a MVP (Minimum Viable Product) for the ncurses library, 2D movement, and as a chance to learn c++.

Game is written entirely in C++ and by myself. No AI Used.

To play, compile via g++ using the following command:

```bash
  g++ main.cpp -lncurses -o main.out
```
